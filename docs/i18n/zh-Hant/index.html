安靜的新標籤頁，隨您心意排列

New Tab Plus 取代 Safari 的新標籤頁，提供您自行打造的儀表板。您可以自由拖曳小工具，並置於每日更換的圖片之上。

在 Mac App Store 取得 需要 macOS 和 Safari

一頁盡覽所有內容

只需開啟所需的 widget，即可將其拖曳至任何佈局中，佈局不會被固定。

您控制的佈局

拖曳任何小工具至任意位置，從角落調整大小，其他小工具會自動移開；偏好使用鍵盤？Tab 至小工具並使用方向鍵。

時鐘與世界時鐘

提供十一種時鐘樣式，從指針式到翻轉式再到文字式，另附可自訂城市的世界時鐘。

天氣一覽

顯示當前天氣狀況、實際體感溫度、逐小時變化及五天預報。

備忘錄與待辦事項

支援 Markdown 的筆記區，以及可手動重新排序並依需要設定到期日的待辦事項清單。

可學習的快速鍵

最常造訪的網站會自動填入，您可自由分組；將重要的網站釘選，隱藏不需要的網站。

小巧工具，無需切換標籤

包含計時器、秒錶、番茄鐘、單位與貨幣轉換器、日曆、名言與 RSS 的應用程式。

每日新照片

精選的太空與自然攝影作品，或是您自己的圖片、漸層或色彩，請將喜愛者釘選並保存。

全鍵盤操作

按下 Cmd+K 即可跳轉至網站、執行搜尋、切換背景或切換任何小工具，無需使用滑鼠。

為您量身打造

支援自訂配色、字型、霧面或實體小工具、已儲存的佈景主題、專注模式，以及您自訂的 CSS。

瀏覽記錄僅保存在您的 Mac 上

New Tab Plus 會根據您實際造訪的網站來填充您的快速鍵，這代表它會要求讀取您開啟的頁面，這是一種嚴格的權限，因此以下是其具體運作方式。

  • 不會將任何內容傳送至任何地方。 您的瀏覽歷史記錄會在 Mac 上計數並儲存，無需帳戶、無分析、無遙測，也無伺服器會接收這些資料。
  • 僅顯示地址，而非頁面。 此延伸功能會記錄您開啟網站的次數，但不會讀取、儲存或傳送頁面內容。
  • 可關閉 隨時暫停追蹤、排除特定網站或清除所有內容；手動新增的捷徑在完全關閉追蹤時仍會繼續運作。
  • 飛航模式 一個開關可停用延伸功能所能建立的所有外傳請求，包含天氣、資訊來源和每日照片。
