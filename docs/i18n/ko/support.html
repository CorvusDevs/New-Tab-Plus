지원

먼저 자주 묻는 질문을 확인하세요. 해당 내용이 없다면 저희에게 연락해 주세요. 실제 사람이 모든 메시지를 확인합니다.

시작하기

  1. New Tab Plus를 Mac App Store 에서 설치하세요.
  2. Safari 를 열고 설정 > 확장 프로그램을 선택합니다.
  3. New Tab Plus를 선택하여 활성화합니다.
  4. 새 탭을 엽니다.

질문

모든 웹사이트를 읽으려는 이유는 무엇인가요?

확장 프로그램이 검색 기록을 읽을 수 없으므로, 자동으로 채워지는 단축키를 제공하려면 사용자가 방문한 페이지를 감지하기 위해 광범위한 웹사이트 접근 권한이 필요합니다.

확장 프로그램은 Mac 에서 주소를 기록하고만 카운트하며, 페이지 내용을 읽거나 외부로 전송하지 않습니다. 추적 기능을 끄고 수동으로 단축키를 추가해도 모든 기능이 정상 작동합니다.

새 탭이 여전히 Safari 기본 페이지를 표시합니다.

Safari > 설정 > 확장 프로그램에서 해당 확장이 선택되어 있는지 확인한 후, Safari 를 완전히 종료하고 다시 시작하세요.

새 탭이 홈페이지로 열리지 않는 경우 설정 > 일반에서 '새 탭 열기'를 홈페이지로 변경하세요.

위젯을 이동하는 방법은 무엇인가요?

오른쪽 상단의 편집 버튼을 클릭한 후 원하는 위치에 위젯을 드래그하거나, 오른쪽 하단 모서리를 드래그하여 크기를 조절한 후 작업이 완료되면 동일한 버튼을 다시 누릅니다.

키보드에서 모든 작업을 수행할 수 있습니다: Tab 을 눌러 위젯에 포커스를 준 후 화살표 키로 이동하고 Shift + 화살표 키로 크기를 조절하며, Cmd+Z 를 눌러 레이아웃 변경을 되돌릴 수 있습니다.

위젯을 추가하거나 제거하는 방법은 무엇인가요?

톱니바퀴 버튼을 눌러 설정을 열고 위젯 섹션을 사용하거나, 편집 모드로 전환한 후 위젯 추가를 누르세요. 모든 위젯을 끌 수 있으며 사용하지 않는 위젯은 비용이 들지 않습니다.

인터넷 연결을 중단할 수 있나요?

네, 설정에서 비행기 모드를 켜면 확장 프로그램이 외부 요청을 전혀 수행하지 않으며, 날씨, 피드, 사진, 아이콘은 모두 작동하지 않고 대시보드만 계속 작동하며 영향을 받은 위젯은 꺼진 것으로 표시됩니다.

노트와 설정이 저장된 위치는 어디인가요?

Mac 의 Safari 로컬 저장소에만 저장되며, 계정이나 동기화는 없습니다. 설정 > 고급 메뉴에서 모든 데이터를 내보내면 다른 Mac 으로 설정을 이동하는 가장 안전한 방법입니다.

매일 사진은 어디에서 가져오나요?

주로 NASA 와 Wikimedia Commons 에서 가져온, 퍼블릭 도메인(자유 이용 저작물) 및 자유 라이선스 우주 및 자연 사진을 엄선한 모음이며, 각 사진은 페이지에 출처를 표기합니다. 직접 만든 이미지나 그라데이션, 단색을 대신 사용할 수도 있습니다.

내 데이터가 어디로 전송되나요?

이 확장 프로그램에는 분석, 원격 감시 또는 서버가 없으며, 개인정보 보호 정책에서 확장 프로그램이 수행할 수 있는 모든 연결과 각 연결에서 수신되는 정확한 정보를 명시하고 있습니다.

고민되시면?

발생한 내용과 예상했던 내용을 알려주시고, macOS 및 Safari 버전을 명시하면 재현 속도가 빨라집니다.
