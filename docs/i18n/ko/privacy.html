개인정보 정책

마지막 업데이트: 2026 년 7 월 17 일

New Tab Plus는 계정, 분석 및 원격 감시 기능이 없으며, 사용자의 데이터를 수신하는 서버를 운영하지 않아 모든 브라우저 활동이 우리에게 도달하지 않습니다. 확장 프로그램이 기록한 모든 정보는 Mac에 남아 언제든지 일시 중지하거나 삭제할 수 있습니다.

수집하는 정보

개인 정보를 수집하거나, 수신하거나, 저장하거나, 판매하거나 공유하지 않으며, 가입 절차도 없고 사용자 식별자도 할당되지 않으며 사용 보고도 수행하지 않습니다.

Mac 에서 계속 유지되는 항목

확장 프로그램이 작동하기 위해 필요한 모든 데이터는 Safari 의 로컬 저장소에 저장되므로, 귀하의 기기에서 안전하게 관리됩니다.

  • 방문 횟수 가장 많이 방문한 단축키를 채우기 위해 확장 프로그램은 방문한 사이트와 시간을 세며 주소와 방문 횟수만 저장합니다.
  • 설정과 콘텐츠 선택한 레이아웃, 위젯, 단축키, 메모, 할 일, 저장된 테마 및 사용자 정의 CSS 설정입니다.
  • 캐시 최근 날씨, 환율 및 사이트 아이콘을 사용하여 페이지를 즉시 로드하고 리소스 사용을 줄입니다.

이 기능은 동기화되지 않으며, 확장 프로그램을 삭제하면 해당 프로그램도 함께 삭제됩니다.

확장 프로그램이 모든 사이트를 읽도록 요청하는 이유

Safari 는 확장 프로그램에 방문한 사이트 목록을 제공하지 않으므로, 자동 채워지는 단축키를 제공하려면 사용자가 방문한 페이지를 감지해야 하며, Safari 는 이에 필요한 광범위한 웹사이트 접근 권한에 대해 강력하게 경고합니다.

저희가 이 권한으로 하는 일의 솔직한 한계는 이렇습니다. 확장 프로그램은 페이지의 주소를 기록하고 Mac 에서 카운터를 하나 늘릴 뿐입니다. 페이지 내용, 양식 필드, 비밀번호 또는 입력하는 어떤 것도 읽지 않으며, 그 어떤 것도 전송하지 않습니다. 이 권한을 부여하고 싶지 않다면 추적을 끄고 단축키를 직접 손으로 추가할 수 있으며, 대시보드의 나머지 기능은 완전히 동일하게 작동합니다.

확장 프로그램이 연결하는 항목

어떤 위젯은 Mac에 저장되지 않은 데이터를 필요로 하며, 아래 연결은 해당 기능을 켤 때만 Mac에서 해당 서비스로 직접 연결되어 우리 식별자가 포함되지 않아 우리가 전혀 확인하지 못합니다.

기능 서비스 연결됨 수신 내용
매일 사진 배경 jsDelivr, GitHub 일일 배경 사진이 선택된 경우에만 사진 목록과 이미지 자체를 요청합니다.
날씨 Open-Meteo 검색 중인 도시 이름과 선택한 위치의 좌표가 표시됩니다. 날씨 위젯이 켜져 있고 위치를 설정한 경우에만 표시됩니다.
단축키 아이콘 사이트 자체, 그다음 대체 수단으로 DuckDuckGo 단축키를 통해 해당 사이트 주소를 가져와 아이콘을 다운로드한 후 로컬에 캐시합니다.
Watchlist prices CoinGecko The symbols you added to the watchlist, to look up their price. Only when the watchlist widget is on.
On this day Wikimedia Today's date, to look up what happened on it. Only when the On this day widget is on.
검색 제안 DuckDuckGo 검색 상자에 입력하는 내용을 입력하는 대로 검색합니다. 기본값은 꺼져 있으며 설정에서 켤 수 있습니다.
통화 변환 Frankfurter 오늘 발행된 환율을 요청하는 것이며, 금액은 전송되지 않으며 변환기의 통화 모드에서만 사용됩니다.
뉴스 피드 추가한 피드 선택한 피드를 요청합니다. 피드 위젯이 켜져 있을 때만 해당됩니다.

비행 모드를 켜면 모든 것이 꺼집니다. 설정의 한 스위치를 켜면 이 표에 있는 모든 연결이 차단되지만 대시보드는 계속 작동하며 영향을 받은 위젯은 이를 표시합니다.

단축기를 검색하거나 여는 경우 Safari 가 해당 사이트를 정상적으로 방문하며, 해당 사이트의 개인정보 정책이 적용됩니다.

제어

  • 방문 추적 중 언제든지 일시 정지하거나 영구적으로 끄는 기능을 제공합니다.
  • 특정 사이트를 제외하여 절대 집계되지 않도록 하세요.
  • 방문 기록을 한 번에 모두 삭제합니다.
  • 항공 모드를 켜서 모든 외부 연결을 차단합니다.
  • 설정을 내보내거나 모든 설정과 데이터를 삭제할 수 있습니다.

어린이

New Tab Plus는 어린이를 대상으로 하지 않으며 어린이를 포함한 누구로부터도 개인정보를 수집하지 않습니다.
