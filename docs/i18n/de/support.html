Unterstützung

Zuerst die häufigsten Fragen. Wenn Ihre nicht dabei ist, schreiben Sie uns; ein echter Mensch liest jede Nachricht.

Erste Schritte

  1. Installieren Sie New Tab Plus aus dem Mac App Store.
  2. Öffnen Sie Safari, dann Einstellungen und dann Erweiterungen.
  3. Aktivieren Sie New Tab Plus zum Aktivieren dieser Funktion.
  4. Öffnen Sie einen neuen Tab. Das ist alles.

Fragen

Warum möchte es jede Website lesen?

Safari lässt Erweiterungen keinen Zugriff auf Ihre Verlaufsgeschichte zu; daher müssen Kurzbefehle, die sich selbst ausfüllen, den breiten Zugriff auf Websites nutzen, um festzustellen, welche Seiten Sie öffnen.

Die Erweiterung notiert lediglich die Adresse und zählt sie auf Ihrem Mac; sie liest niemals den Seiteninhalt und sendet nichts an einen externen Server. Sie können die Verfolgung deaktivieren und Kurzbefehle manuell hinzufügen, wobei alle anderen Funktionen weiterhin einwandfrei funktionieren.

Mein neuer Tab zeigt immer noch die Standardseite von Safari an.

Stellen Sie sicher, dass die Erweiterung in Safari unter Einstellungen > Erweiterungen aktiviert ist; falls ja, beenden Sie Safari vollständig und starten Sie es neu.

Safari verfügt über eine eigene Einstellung für den Inhalt eines neuen Tabs; unter Einstellungen > Allgemein legen Sie "Neue Tabs öffnen mit" auf Startseite fest, falls die Überschreibung ignoriert wird.

Wie verschiebe ich Widgets?

Klicken Sie auf den Bearbeitungsbereich oben rechts, ziehen Sie dann das Widget an den gewünschten Ort oder ziehen Sie an der rechten unteren Ecke, um es zu vergrößern oder zu verkleinern, und drücken Sie den gleichen Bereich erneut, wenn Sie fertig sind.

Sie können dies ebenfalls vollständig über die Tastatur erledigen: Drücken Sie Tab, bis ein Widget fokussiert ist, verwenden Sie dann die Pfeiltasten zum Verschieben und Shift mit den Pfeiltasten zum Ändern der Größe; Cmd+Z rückgängig machen eine Layout-Änderung.

Wie füge ich ein Widget hinzu oder entferne ich eines?

Öffnen Sie die Einstellungen über das Zahnrad-Symbol und nutzen Sie den Abschnitt Widgets, oder wechseln Sie in den Bearbeitungsmodus und drücken Sie auf Widget hinzufügen. Jedes Widget kann deaktiviert werden, und die nicht genutzten Widgets verursachen keine Kosten.

Kann ich die Internetverbindung unterbrechen?

Ja. Schalten Sie den Flugmodus in den Einstellungen ein; dann sendet die Erweiterung keine ausgehenden Anfragen mehr, weder Wetter noch Feeds, Fotos noch Symbole, das Dashboard funktioniert weiterhin und die betroffenen Widgets zeigen an, dass sie deaktiviert sind.

Wo werden meine Notizen und Einstellungen gespeichert?

In der lokalen Speicherung von Safari auf Ihrem Mac und nirgendwo sonst; es gibt kein Konto und keine Synchronisation; Sie können alles unter Einstellungen > Erweitert exportieren, was auch der sicherste Weg ist, Ihre Einrichtung auf einen anderen Mac zu übertragen.

Woher stammen die täglichen Fotos?

Es handelt sich um eine kuratierte Sammlung gemeinfreier und frei lizenzierter Weltraum- und Naturfotografie, hauptsächlich von NASA und Wikimedia Commons. Jedes Bild nennt seine Quelle auf der Seite. Sie können stattdessen auch Ihr eigenes Bild, einen Farbverlauf oder eine einfache Farbe verwenden.

Wird meine Daten irgendwohin gesendet?

Nein, es gibt keine Analysen, keine Telemetrie und keinen Server unsererseits; die Datenschutzrichtlinie listet jede Verbindung der Erweiterung und genau den Inhalt jeder einzelnen auf.

Noch feststecken?

Erzählen Sie uns, was passiert ist und was Sie erwartet haben. Das Nennen Ihrer macOS- und Safari-Version hilft uns, das Problem schneller zu reproduzieren.
