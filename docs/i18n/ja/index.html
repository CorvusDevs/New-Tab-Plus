静かな新しいタブページを、あなたの好みに整えます

New Tab Plus は、Safari の新しいタブを、毎日変わる写真の上に好きな場所にウィジェットをドラッグして作成したダッシュボードに置き換えます。

Mac App Store で入手 macOS と Safari が必要です

すべての情報が 1 ページにまとめられています。

必要なウィジェットだけをオンにして、任意のレイアウトにドラッグして配置できます。固定されることはありません。

制御可能なレイアウト

ウィジェットをどこでもドラッグしてサイズ変更し、他のウィジェットを動かすことができます。キーボードを好む場合は、Tab キーでウィジェットを選択し、矢印キーで移動します。

時計と世界時計

アナログ、フリップ、ワードクロックなど 11 種類のクロックフェイスに加え、気になる都市用の独立した世界時計を備えています。

天気概要

現在の気象条件、実際の外気温、1 時間ごとの変化、5 日間の予報を表示します。

メモとタスク

マークダウンを理解するメモ帳と、必要な場合に手動で順序を並び替えて期限を設定できるタスクリストです。

学習するショートカット

よく訪れるサイトが自動で入力され、好きなようにグループ化できます。重要なサイトはピン留めし、不要なサイトは非表示にできます。

小型ツールで、タブは不要

タイマーとストップウォッチ、ポモドーロ、単位と通貨の換算機、カレンダー、名言、RSS が搭載されています。

毎日新しい写真

厳選された宇宙や自然の写真、あるいはご自身の画像、グラデーション、または色。お気に入りをピン留めして保存できます。

すべてをキーボードで

Cmd キー + K キーを同時に押して、サイトへのジャンプ、検索の実行、背景の切り替え、またはウィジェットの有効化/無効化を行えます。

あなたに合わせた

アクセントカラー、フォント、すりガラスまたは不透明なウィジェット、保存されたテーマ、フォーカスモード、そして必要であれば独自の CSS をサポートします。

閲覧内容は Mac にとどまります

New Tab Plus は、実際に訪問したサイトからショートカットを埋め込みます。つまり、開いたページを読み取るよう求められ、これは重大な権限であるため、その具体的な動作を説明します。

  • どこにもデータは送信されません。 訪問履歴は Mac でカウントされ、Mac に保存されます。アカウント、分析、テレメトリ、および送信先となるサーバーは存在しません。
  • アドレスのみで、ページの内容ではありません。 この拡張機能は、あなたがサイトを開いたことと頻度を記録しますが、ページの内容を読み取ったり保存したり送信したりしません。
  • オフにできます 追跡を一時停止、特定のサイトを除外、またはいつでもすべてをクリアできます。手動で追加したショートカットは、追跡を完全にオフにしても引き続き機能します。
  • 飛行機モード 拡張機能が送信しうるすべての外部リクエスト（天気、フィード、毎日の写真など）を停止する 1 つのスイッチです。
